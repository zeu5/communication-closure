# Communication closure of protocols

This repository is an experiment in trying to get AI to prove certain properties of distributed protocols. Specifically, the idea of [communication closure](https://members.loria.fr/Stephan.Merz/papers/rp2009.pdf).

Why? Because it is [easier to test](https://dl.acm.org/doi/10.1145/3428278) the protocols if they are communication closed.

The repo will prove in Lean for specific protocols.
